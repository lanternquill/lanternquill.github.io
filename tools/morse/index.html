Pocket Morse Nameplate

Type a word to see it as International Morse code, one labelled group per letter.

Word

Letters only: no spaces, numbers or punctuation. Lowercase is shown as uppercase.

Nameplate

Examples

  • A = .-
  • B = -...
  • SOS = ... / --- / ...

In the SOS example, / separates one letter's code from the next. A dot is written . and a dash is written -.

This page is a visual reference only. It is not a transmitter or an emergency signalling device.
